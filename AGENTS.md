# TimeAtlas - AI Instructions

## Project
TimeAtlas is an Expo React Native application.

## Tech Stack
- Expo
- React Native
- TypeScript
- pnpm

## Package Manager
Always use pnpm.

Do not use:
- npm
- yarn

Examples:
- `pnpm add <package>`
- `pnpm remove <package>`
- `pnpm expo install <package>`
- `pnpm expo start`

## Code Rules
- Use TypeScript.
- Prefer functional components.
- Use React hooks where appropriate.
- Keep components small and reusable.
- Avoid unnecessary dependencies.
- Follow the existing project structure.
- Do not modify unrelated files.

## Before Making Changes
1. Understand the existing code.
2. Check related components/files.
3. Explain the approach for larger changes.
4. Make the smallest reasonable change.

## UI
- Keep the UI clean and modern.
- Reuse existing components where possible.
- Maintain consistent spacing, typography, and colors.
- Ensure layouts work on both iOS and Android.

## Testing
After making changes:
- Run TypeScript checks.
- Check for lint errors.
- Verify the Expo app builds/runs correctly.

## Important
Do not make architectural changes without explaining why.
Do not install a new package if the requirement can be solved with the existing dependencies.
